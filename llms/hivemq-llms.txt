# HiveMQ

> HiveMQ is the real-time industrial data platform built on MQTT, developed by HiveMQ GmbH (Berlin, Germany). It provides an enterprise-grade MQTT message broker for reliable, scalable, secure bidirectional data movement between IoT/OT devices and enterprise IT systems, spanning the self-managed HiveMQ Broker, managed HiveMQ Cloud, HiveMQ Edge, Data Hub, and Pulse. It fully supports MQTT 3.1.1, MQTT 5.0, and Sparkplug B.

## Products
- [HiveMQ Broker](https://www.hivemq.com/products/mqtt-broker/): Enterprise self-managed MQTT broker.
- [HiveMQ Cloud](https://console.hivemq.cloud/): Fully managed MQTT broker service.
- [HiveMQ Edge](https://www.hivemq.com/products/edge/): Software edge gateway bridging OT protocols (OPC-UA, Modbus) to MQTT.
- [HiveMQ Data Hub](https://www.hivemq.com/products/data-hub/): In-broker data policy, validation, and transformation.
- [HiveMQ Pulse](https://www.hivemq.com/products/pulse/): Distributed data intelligence platform.
